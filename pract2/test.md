# Тестовый документ

Это "первый абзац" с кавычками.

## Код

Пример кода с "описанием":

```python
def hello():
    print("Hello, World!")
    return "результат"
```

Инлайн код: `x = "значение"` тоже не должен изменяться.

## Вложенные кавычки

Текст "с кавычками и `код "внутри"` кавычек".

## Парность кавычек

Первая пара: "открываем" и закрываем.
Вторая пара: "снова открываем" и закрываем.

```javascript
const message = "Это JavaScript код";
console.log("Кавычки здесь не меняются");
```

Обычный текст "после блока кода" продолжается.
